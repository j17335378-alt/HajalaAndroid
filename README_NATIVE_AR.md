# حجالة - واجهة أندرويد أصلية (مرحلة أولى)

هذه النسخة تجعل شاشة البداية واجهة Android Views أصلية ولا تفتح صفحة الموقع تلقائيًا داخل WebView. تشمل حاليًا شاشة رئيسية، تنقلًا سفليًا، صفحات أولية للمانغا والأصدقاء والملف الشخصي، واستوديوًا يستطيع فتح منتقي ملفات أندرويد لاختيار الصور والفيديوهات.

## حدود هذه المرحلة
- هذه ليست إعادة كتابة مكتملة لكل وظائف الموقع. قارئ المانغا، الحسابات، الرسائل، تيك جيل، وتشغيل الفيديو الأصلي ما زالت تحتاج نقل وربط فعليًا.
- اختيار الوسائط يعمل كاختيار محلي مبدئي، لكن الحفظ الدائم، المعاينة الكاملة، النشر، والمزامنة ليست مكتملة.
- لم يتم إنشاء APK أو اختباره على جهاز حقيقي في هذه البيئة.
- `MainActivity.java` الأصلي محفوظ للمساعدة في نقل الوظائف الموجودة لاحقًا؛ نقطة التشغيل في هذه النسخة هي `NativeHomeActivity`.

## البناء
افتح المجلد `HajalaAndroid` في Android Studio، نفّذ Gradle Sync ثم Build > Build APK(s). يتطلب المشروع Android SDK 36 وJDK 17 حسب إعداداته الحالية.

## قسم MangaVerse (أصلي بالكامل)
- تبويب «مانغا» يعرض MangaVerse: زر «نشر عمل جديد»، فلاتر (الكل/مانغا/مانهوا/ونشوت)، وشبكة أغلفة لأعمالك.
- شاشة «نشر عمل جديد»: النوع، رفع الغلاف من الهاتف، العنوان، الوصف، والتصنيفات.
- زر «+ تصنيف» يضيف تصنيفًا من عندك ويُحفظ على الجهاز؛ اضغط مطولًا على تصنيفك لحذفه.
- الأعمال والتصنيفات تُحفظ محليًا (SharedPreferences) ولا ترفع لأي خادم بعد.
- كل الأزرار لها أنميشن ضغط (تصغير مع ارتداد) وتأثير Ripple، عبر `Ui.java`.
- الملفات الجديدة: `Ui.java`، `Store.java`، `FlowLayout.java`، `MangaVerseScreen.java`، `PublishScreen.java`، وأيقونات `res/drawable/ic_*.xml`.
