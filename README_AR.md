# مشروع حجالة المحسّن لأندرويد 🦋

هذا مشروع أندرويد يضم نسخة محسّنة من موقع حجالة داخل WebView، ويستخدم أصل التطبيق المحلي `https://appassets.androidplatform.net/` كي يعمل التخزين المحلي كما يعمل في موقع HTTPS عادي.

## التغييرات في هذه النسخة

- تضمين ملف الموقع المحسّن داخل التطبيق، مع أيقونة حجالة ذات الإطار الذهبي والفراشات.
- إزالة مشغّل فيديو شاشة البداية المشفّر، وإبقاء شاشة تحميل متحركة تظهر زر **دخول إلى حجالة** أسفلها بعد جاهزية الصفحة أو بعد انتهاء مهلة احتياطية.
- حذف أدوات رفع جودة الصور والفيديو القائمة على إعادة الرسم داخل `Canvas`، وإزالة إعادة ضغط صور صفحات المانغا عند ضبط الجودة، وإلغاء دمج العلامة المائية عن طريق إعادة رسم الصفحة كاملة. تظهر العلامة المائية كطبقة واجهة فوق الصورة دون تعديل الأصل. تبقى الصور والفيديوهات قابلة للعرض والتنزيل بملفها الأصلي؛ الجودة القصوى هي جودة المصدر نفسه، ولا توجد خوارزمية يمكنها استعادة تفاصيل غير موجودة بالمصدر.
- استبدال نظام تلوين الصفحات الثقيل بالذكاء الاصطناعي وملفات النموذج الكبيرة بفلاتر CSS خفيفة: أصلي، دافئ، وردي، بارد، بنفسجي وذهبي، مع تحكم بسيط في شدة التأثير.
- تقليل التحميل المسبق للفيديو إلى بيانات الوصف `metadata` حتى يبدأ التشغيل عند الطلب بدلاً من محاولة جلب الفيديو كله مبكراً.
- تحسين التفاف الأزرار وأشرطة المشغل وعناصر القراءة على الشاشات الصغيرة ومنع التمدد الأفقي قدر الإمكان.
- إبقاء `localStorage` و`IndexedDB` مفعّلين داخل مساحة التطبيق، مع طلب تفعيل التخزين الدائم من WebView عند دعمه. البيانات المحفوظة محلياً لا تحتاج اتصالاً مستمراً، لكن جلب المصادر الخارجية والخطوط والترجمة وبعض الوظائف يعتمد على الإنترنت.
- إضافة نقطة API محلية مضمّنة في نسخة أندرويد لجلب المصادر العامة عبر HTTPS عند منع CORS؛ لا تحتاج تشغيل `hajala_server.py` منفصلاً. الخدمة لا ترسل ملفات تعريف ارتباط للمواقع عبر وسيط الجلب ولا تتجاوز تسجيل الدخول أو حماية المواقع. حدود الأمان الحالية للجلب: 8 MiB لصفحات النص و64 MiB للملفات الأخرى.
- فتح منتقي ملفات أندرويد للرفع، وتمرير تنزيلات `blob:` و`data:` إلى مجلد التنزيلات، ودعم التشغيل بملء الشاشة.

## بناء APK

### عبر Android Studio

1. فك ضغط ملف المشروع وافتح مجلد `HajalaAndroid` في Android Studio.
2. ثبّت JDK 17 وAndroid SDK Platform 36 وBuild Tools 36.0.0 عند طلب Android Studio ذلك.
3. نفّذ Gradle Sync، ثم من القائمة اختر **Build → Build APK(s)**.
4. عند نجاح البناء ستجد الملف هنا:

   `app/build/outputs/apk/debug/app-debug.apk`

### عبر GitHub Actions

1. ارفع محتويات المشروع إلى مستودع GitHub خاص بك.
2. افتح **Actions**، ثم **Build Hajala APK**، ثم **Run workflow**.
3. عند نجاح التشغيل، نزّل `hajala-debug-apk` من قسم Artifacts، وستجد داخله `app-debug.apk`.

يتطلب أول بناء اتصالاً بالإنترنت لتنزيل Gradle ومكوّنات SDK. بيئة إعداد هذه النسخة لا تحتوي Android SDK متكاملاً، لذلك **ملف APK غير مبني ضمن الحزمة حالياً**؛ الحزمة تحتوي مشروع البناء وملفات المصدر.

## التخزين والتحديثات

يُخزّن التطبيق بيانات `localStorage` و`IndexedDB` في مساحة WebView الخاصة بالتطبيق. تبقى البيانات عادة بعد تحديث التطبيق إذا استُخدم معرّف التطبيق نفسه وتوقيع التحديث المتوافق. **حذف التطبيق أو مسح بياناته قد يحذف المكتبة والإعدادات المحلية**، لذلك صدّر نسخة احتياطية من بياناتك المهمة قبل أي تغيير كبير.

## حدود يجب معرفتها

- اختبارات JavaScript النحوية نجحت للصفحة المعدّلة، لكن ما زال يلزم اختبار التثبيت والأداء الفعلي على هاتف أندرويد قبل اعتبارها نسخة نهائية خالية من الأخطاء.
- الجلب الخارجي يعتمد على جودة الإنترنت، وعلى أن يسمح الموقع بالوصول. لا يمكن ضمان عمل كل مصدر أو تجاوز تسجيل الدخول والحماية.
- تلوين الصفحات الحالي مجرد فلاتر بصرية خفيفة، لا يغيّر ملف الصورة الأصلي ولا يحفظ نسخة ملوّنة جديدة.
- التنزيل بأعلى جودة ممكنة يعني حفظ الملف الذي يقدّمه المصدر من دون إعادة ضغط من حجالة؛ إذا كان المصدر نفسه منخفض الجودة فستبقى جودته كما هي.


## إصلاحات نسخة Android Media/Layout v2
- تحسين منتقي الصور والفيديو داخل WebView مع مسار احتياطي عبر منتقي ملفات أندرويد.
- ضبط مساحة أسفل الشاشة وأزرار عارض الوسائط حتى لا تتداخل مع شريط النظام على الشاشات القصيرة.
- إضافة تحميل كسول للصور وتحديد preload للفيديوهات خارج المشغل لتقليل التقطيع والضغط على الذاكرة.
- إزالة نظام البوتات من واجهة تيك جيل كما في نسخة المشروع المرفقة.

مهم: هذه نسخة إصلاح انتقالية وما زالت واجهة الموقع تعمل داخل WebView. ليست إعادة كتابة كاملة بواجهة Kotlin/Compose أصلية، ولم يتم بناء APK أو اختبارها على هاتف فعلي في بيئة الإنشاء هذه. روابط الفيديو الخارجية التي تمنع التنزيل عبر CORS أو سياسات المصدر قد تحتاج خادم وسيط مصرحًا به أو رابط تنزيل مباشر من المصدر.
